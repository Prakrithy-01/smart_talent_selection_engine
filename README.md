\# 🧠 "Smart Talent" Selection Engine



An AI-driven HR Tech recruitment tool that eliminates the limitations of primitive keyword-matching ATS systems. This application parses multi-format resumes, extracts technical skills into standardized profiles, and leverages vector embeddings to rank candidates semantically based on a Job Description (JD).
